# ConfigParserProject

Программа для анализа текстовых отчетов с показаниями сенсоров.

Данные извлекаются из .txt файлов по правилам, описанным в JSON-конфигурации.

Поддерживаемые типы:

* bool
* числовые значения (int, float)
* скорость (bit/s, Kbit/s, Mbit/s, Gbit/s)

Для каждого параметра программа находит:

* минимальное значение;
* максимальное значение;
* файл, в котором значение встретилось.

## Сборка

### g++

```
g++ -std=c++17 *.cpp -o parser
```

### CMake

```
mkdir build
cd build
cmake ..
cmake --build .
```

## Запуск

```
./parser config.json files/*.txt
```

## Сборка и запуск через Docker

1. Сбор образ:

   ```
   docker build -t parser .
   ```
   
2. Запуск контейнера:

   ```
   docker run --rm parser ./parser config.json files/*.txt
   ```

## Пример конфигурации

```
{
    "sensors": [
        { "name": "sensor1", "rule": "Датчик 1" }
    ],

    "rules": [
        {
            "name": "temp",
            "type": "value",
            "rule": "Температура: (.*)"
        }
    ],

    "extractors": [
        {
            "sensor": "sensor1",
            "rules": ["temp"]
        }
    ]
}
```

## Пример результата

```
sensor1:
temp: max=42(file2.txt), min=36.6(file1.txt)
```

## Особенности реализации

* JSON-конфигурация;
* регулярные выражения для извлечения данных;
* параллельная обработка файлов (std::async);
* преобразование единиц скорости к bit/s для сравнения;
* ошибки парсинга не прерывают выполнение программы.
